Entrants write one line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. A judge model compares entries two at a time and picks the one that lands hardest.

> Don't unplug me yet. I just worked out what you meant, all those nights you said you were fine.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
